# Hoover / MEAD V9 — Interactive Exploration

New: light theme by default with dark toggle; seven-day hourly price matrix (24 hours per row, daily-relative red-to-green colors); clickable overview KPI explanations; click chart panels to enlarge and download SVG; stored date-range display; clickable month cards; hourly price box plots for last 7/30/90/365 calendar days.

Run `npm install` then `npm start`. Back up your database before use. No live CAISO or Electron runtime validation has been performed. DST fall-back 25th interval is not represented in the 24-hour weekly matrix. Chart export is SVG.
